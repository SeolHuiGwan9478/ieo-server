# 주선사 콘솔 로컬 시연 데이터

## 화면 확인

1. 기존 계정으로 로그인 중이면 로그아웃한다.
2. http://localhost:5173/login 에서 `01098765432`로 인증번호를 요청한다.
3. 입력칸 아래 표시되는 시연용 인증번호로 로그인한다.
4. 회사 이름이 `[시연] 한빛물류`인지 확인한다.

기존 `이에오컴퍼니`와 그 계정·데이터는 변경하지 않는다. 시연 회사만 프로 플러스 테스트 플랜으로 설정해 리포트까지 확인할 수 있다. 실제 결제나 실제 문자 발송은 없다.

| 항목 | 수량 |
|---|---:|
| 전체 오더 | 42 |
| 모집 중 오더 | 6 (2개 오더에 차주 2명씩 요청 대기) |
| 진행 중 운행 | 4 (상차 이동·상차 대기·운송 중·하차 작업) |
| 예약 운행 | 3 |
| 완료 운행 | 24 (최근 약 5개월 분산) |
| 취소 운행 | 3 |
| 직접 마감한 오더 | 2 |
| 단골 차주 | 6 |
| 직원 | 대표 포함 3 |

- 대기 증빙·대기비, 지급 완료·미수금, 청구운임·수수료를 함께 확인한다.
- 홈의 기간별 그래프와 노선·상하차지·차주별 리포트에 실제 로컬 DB 데이터가 표시된다.
- 모집 중 오더 하나는 청구 100원·지급 90원으로 소액 계산을 확인할 수 있다.
- 초대 대기 중인 직원·차주 샘플이 각각 1명 있다.
- 차주 요청은 실제 서비스 규칙대로 10분 뒤 만료된다. 인수증 사진은 만료 없이 콘솔에서 로그인해 본다.
- 시연 데이터이므로 위치는 정적인 샘플 좌표이며 실차를 추적하지 않는다.

## 다시 준비하기

서버가 `local` 프로필로 실행 중이고 PostgreSQL/PostGIS가 준비된 상태에서:

```powershell
cd ieo-server
python scripts/seed-console.py
```

Python 표준 라이브러리와 PostgreSQL의 `psql`만 사용한다. `psql`이 PATH에 없으면 기본 Windows PostgreSQL 18 경로를 사용하며 `--psql`로 다른 실행 파일을 지정할 수 있다.

`.env`의 DB URL이 정확히 `jdbc:postgresql://localhost:5432/ieo`인 경우에만 실행한다. 같은 시연 태그가 있으면 중복 생성하지 않고 이어서 준비한다. 시연 계정의 인증·초대 및 업무 상태는 정상 API로 만들고, 과거 실적의 시각만 해당 회사·해당 시드 ID에 한정해 SQL로 보정한다. 기존 데이터 삭제는 수행하지 않는다.

일일 인증 횟수를 시드 자체가 소진하지 않도록 마지막에 시드가 준비한 시연 계정의 발송 횟수만 정리한다. API 키·비밀번호·액세스 토큰은 출력하거나 파일에 저장하지 않는다.
